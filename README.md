# HR-ANALYTICS-DASHBOARD
## Objective 
An interactive HR Analytics Dashboard build to help organization monitor workforce trends,employee attrition,demographics and job satisfaction metrics in a visually intuitive way.This dashboard provides actionable insights for HR teams and management to improve employee retention and workforce planning.

## Raw Data 

* https://github.com/itumaity29-eng/HR-ANALYTICS-DASHBOARD/blob/main/HR%20Data.xlsx

## Features

KPI cards:

Quick overview of important workforce statistics

* Total Employees
* Attrition Count
* Attrition Rate
* Active Employees
* Average Age

Department-wise Attrition:

Pie chart visualization showing attrition distribution across

* R&d
* Sales
* HR

Age Group Analysis:

Stacked bar chart displaying 

* Employee count by age band
* Gender distribution within each age group

Job Satisfaction Analysis:

Heatmap/table showing satisfaction ratings across different job roles.

Education Field Attrition:

Bar chart identifying attrition trends based on education background.


Gender- based Attrition by Age:

Donut charts visualizing attrition differences betwen male and female employees across age groups.


Interactive slicer:

An education degree slicer to filter dashboard insights based on employee education levels.
